原理

音箱里的声音，
会被麦克风再收一遍

所以队友会听到你的游戏声，还有他们自己的回声。VoiceAec 同时听麦克风和扬声器正在放的声音，把后者从前者里减掉，再交给语音软件。

没有 VoiceAec

队友听到整个房间

你的说话声、音箱里的游戏声、队友自己的语音，一起进了麦克风。想让对方听清楚，只能戴耳机，或者把音量压得很低。

队友听到的人声 + 游戏声 + 回声
得戴耳机或把音量压低队友听到自己的回声
开着 VoiceAec

减掉音箱，留下你的声音

麦克风和参考回采（扬声器正在放的声音）一起进入本机模型。扬声器那部分被减掉，剩下的人声写进虚拟声卡，语音软件从那里取声音。

队友听到的主要是你的说话声
游戏照常外放不用戴耳机语音软件选 CABLE Output

效果取决于麦克风位置、音量和房间。VoiceAec 不保证完全消除，但能明显压低外放串音。

接线只要记住四个位置

最常见的错误：两个 CABLE 选反
  1. 游戏 / 音乐的播放设备耳机或音箱和平时一样，不用改
  2. VoiceAec 参考回采同一个耳机或音箱告诉 VoiceAec 正在放什么
  3. VoiceAec 输出CABLE Input处理后的声音写进虚拟声卡
  4. 语音软件的麦克风CABLE Output从虚拟声卡取处理后的声音

设好一次，
之后基本不用管

实时

每 16 毫秒处理一次

回声消除（AEC）把麦克风和参考回采一起送进 LocalVQE 神经网络，在本机 CPU 上推理，不联网。音频按 16 毫秒切成一段，称为一跳，正常每秒约 62.5 跳。

常见问题

遇到问题，
先看这里

这里只列最常见的几种。没找到你的情况，手册里有按症状分类的排障步骤。

查看完整手册 在 GitHub 提问
Q 对方还是能听到回声或游戏声？

先查参考回采：它要选你实际出声的耳机或音箱，放音乐时电平应该在跳。再确认语音软件的扬声器没有选成 CABLE Input。都没问题的话，把模式从均衡换成强力试试。

Q 装完找不到 CABLE Input / Output？

VB-CABLE 装完要重启电脑，设备才会出现。重启后，播放设备里有 CABLE Input，录音设备里有 CABLE Output。还是没有，就重跑安装包，或者点面板顶部的一键安装。卸载 VoiceAec 不会删掉它。

找不到 CABLE 时，v0.5.0 起程序会以暂停状态打开，不会把麦克风播到音箱里；v0.5.2 起点「恢复」也会被拦下。先在输出下拉里手动选一个设备，或者装好 CABLE 后点「重新检测」。重启后设备一般会自动恢复。

Q 模式会记住吗？

v0.4.8 起会。在面板或托盘切换后写入 voiceaec.json，下次启动（包括开机自启）自动恢复。想临时换一种，在快捷方式目标末尾加 --model v1.3，只影响这一次，不写回配置。

Q 关掉窗口是不是就退出了？

不是。点 X 只是收起面板，处理在托盘里继续。要退出，右键托盘图标选“退出 VoiceAec”。想临时停一下，用“暂停并静音”，恢复后设备和模式不变。

Q 暂停后关掉程序，下次还会暂停吗？

v0.4.9 起会。暂停状态写入配置，关掉或重启后还是暂停，点“恢复处理与输出”继续。运行中正常退出，下次启动照常运行。

Q OBS 插件装不上，或者加了没效果？

安装前要完全退出 OBS，一键安装只支持普通安装版的 64 位 OBS。装完重启 OBS，在麦克风的音频滤镜里添加 VoiceAec，把 Reference source 选成桌面音频或游戏音频源。

Q QQ 提示 CABLE Output 加载失败？

这是 QQ 对虚拟设备的兼容问题，音频链路一般没坏。可以重新选一次 CABLE Output、重启 QQ，或者换 Oopz、Discord、游戏自带语音试试。别的软件都正常，就只能等 QQ 修复。

Q 手机打开局域网面板，字很小怎么办？

局域网面板是桌面布局，手机上会挤。横屏或用平板看电平、切模式比较方便，复杂设置回电脑上做。面板没有登录密码，只在可信的家用网络里用，不要把端口转发到公网。
