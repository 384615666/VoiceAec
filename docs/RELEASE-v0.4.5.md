# v0.4.5 · 局域网访问

## 下载

| 文件 | 说明 |

均自包含（免 .NET 运行时），已内置全部模型。

## 本版更新

- **面板支持局域网访问**：默认监听全部网卡，同一 Wi-Fi 下的手机 / 平板可直接打开 `http://192.168.x.x:8765/`，无需密码（按家庭局域网场景设计）。
- **「关于」显示局域网地址**：开启时显示当前地址并可直接点击打开；拿不到地址时（未授权/无局域网）该行自动隐藏。
- **安装器自动配置**：一次管理员授权完成 http.sys URL 预留（`http://+:8765-8774/`）与 Windows 防火墙私有网络入站规则，装完即可用；便携版需要以管理员身份运行一次安装器，或用 `--no-lan` 只用本机面板。
- 仅接受私有网段（192.168/16、10/8、172.16/12）访问，并继续校验 Host / Origin 以防 DNS rebinding。
- 其余与 v0.4.4 一致（默认安装虚拟声卡、向导配图、关于面板、OBS 插件管理）。

## 安全提示

面板可以对局域网开放且没有密码，任何能连到你家庭网络的人都能打开并调整设置。建议只在可信的家庭网络使用；不想要局域网访问时，给快捷方式加 `--no-lan` 参数即可恢复为仅本机。
