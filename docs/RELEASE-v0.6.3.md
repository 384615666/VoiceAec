## 本版更新

- **新增「固定默认麦克风」守护**：开机自启时，虚拟声卡（CABLE Output）往往比实体麦克风晚就绪，Windows 会把系统默认输入先分给实体麦克风且不会切回——QQ / 游戏语音因此录到没消回声的原声。现在程序启动后会把 Windows 的三种默认输入角色（默认设备 / 多媒体 / 通信）统一设为 CABLE Output，设置后读回核实。
- **守护只做一次**：核实成功后本轮进程不再检测默认麦克风，后续设备通知也不会重新纠偏（之后你手动改默认设备不会被抢回）。没成功时前 30 轮（约一分钟）兜底重试，之后只在设备插拔 / 默认值变化时再试；暂停处理时不纠偏。顶栏与托盘菜单都有开关，默认开启；关闭再打开会重新纠偏一次。
- **修复启动回退"粘住"**：配置的麦克风开机时还没就绪，程序会临时改用系统默认麦克风且一直不切回（只能手动换）。现在设备一出现就自动切回你配置的麦克风；临时回退期间面板会提示「已临时改用×××，接回后会自动切回」。
- **防回授保护**：默认麦克风被固定到 CABLE Output 后，启动期的临时回退绝不选用任何 CABLE 设备——否则会把处理完的声音又采回输入形成啸叫；找不到实体麦时宁可保持暂停，设备接好后自动恢复。
- 开机自动纠偏要生效，需同时开启「开机自启」和「固定默认麦克风」。

音频处理、设备热插拔自愈、界面与其它功能与 v0.6.2 一致。
