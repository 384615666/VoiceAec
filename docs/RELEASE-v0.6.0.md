# v0.6.0 · 中英双语界面、无边框窗口与英文封面

## 下载

| 文件 | 说明 |
|---|---|
| `VoiceAec-v0.6.0-setup-x64.exe` | **推荐**。安装版：每用户安装，自动创建开始菜单/桌面快捷方式。 |
| `VoiceAec-v0.6.0-win-x64.zip` | 便携版：解压即用，配置写在 exe 旁 `voiceaec.json`。 |

## 本版更新

- **中英双语界面**：面板、托盘菜单、状态提示和错误消息支持中文 / English。打开「关于」，点右上角「关闭」旁边的按钮切换（中文界面显示 `EN`，英文界面显示 `中文`），立即生效；选择写入 `voiceaec.json` 的 `lang`，重启后保持。
- **无边框自绘窗口**：去掉 Windows 原生标题栏，右上角改为自绘的最小化 / 最大化（还原）/ 关闭按钮；按住顶部任意空白拖动窗口（包括最顶部边缘），双击最大化 / 还原，四边四角可缩放。最大化精确贴满当前显示器工作区、不盖任务栏，也不会跳到其他显示器；关闭按钮仍然只是隐藏到托盘。
- **大窗口自适应**：最大化 / 全屏时面板按可用空间等比放大（1×–2×），弹窗、设备菜单同步缩放。
- **局域网地址点击复制**：「关于」里显示的 `http://192.168.x.x:8765/` 点一下就复制到剪贴板（WebView2 由宿主写剪贴板；手机浏览器使用浏览器剪贴板回退），方便发到手机。
- **英文封面**：`README.en.md` 顶部换成英文封面 `docs/images/og-cover-site-en.png`；中英文 README 补充双语界面、无边框窗口与复制地址说明。
- **文档更新**：官网与图文手册新增「界面语言」「窗口操作」章节和复制地址说明，「关于」截图更新为带语言切换按钮的版本。
- **修复**：OBS 插件提权安装 helper 未应用界面语言，导致英文界面下安装/卸载结果消息仍为中文的问题。

音频处理与其它功能与 v0.5.3 一致；界面默认中文。

## 已知限制

- 在 OBS 插件或 VB-CABLE 任务完成后切换语言，已生成的结果消息会保留完成时的语言；重新打开 OBS 插件对话框会刷新状态。
- 无边框窗口没有 Windows 11「悬停最大化按钮弹出贴靠布局」这一原生标题栏特性；把窗口拖到屏幕边缘贴靠仍可使用。
- 中文手册与官网目前只有中文版；英文界面适合不熟悉中文的用户。
