# v0.4.4 · 安装向导重做

## 下载

| 文件 | 说明 |
|---|---|
| `VoiceAec-v0.4.4-setup-x64.exe` | **推荐**。安装版，默认一并安装 VB-CABLE 虚拟声卡（可取消）。 |
| `VoiceAec-v0.4.4-win-x64.zip` | 便携版，解压即用；首次启动可按面板提示一键安装虚拟声卡。 |

均自包含（免 .NET 运行时），已内置全部模型。

## 本版更新

- **安装选项默认勾选**：桌面快捷方式与 VB-CABLE 虚拟声卡都默认选中，一路"下一步"即可；不再受上次安装（例如静默安装）状态影响。
- **虚拟声卡文案**：改为「安装 VB-CABLE 虚拟声卡（必装，装完需重启）」；列表下方固定显示完整署名："VB-CABLE 由 VB-Audio 免费提供（donationware，欢迎赞助）。来源 www.vb-cable.com；VoiceAec 仅分发未经修改的官方安装包，卸载 VoiceAec 不会移除该驱动。"
- **完成页明确提示重启**：装完显示"虚拟声卡已安装，请重启电脑；重启后才能在外放的同时消除回声，并在语音软件里选中 CABLE Output"，并给出卸载入口指引。
- **安装向导换肤**：左侧大图与右上角图标换成猫咪麦克风 + 奶油/薄荷/天蓝渐变（含 100/125/150/200% 多倍图），替换默认的蓝色纸箱图标。
- **关于面板补充卸载说明**：文章末尾说明"设置 → 应用 → VoiceAec"或开始菜单的卸载入口。
- 其余与 v0.4.3 一致（默认安装虚拟声卡、缺声卡回退与一键安装、OBS 插件管理、v1.4 数值修复）。

## 关于卸载程序

安装时一直会生成：安装目录下的 `unins000.exe`、开始菜单「VoiceAec → 卸载 VoiceAec」，以及 Windows「设置 → 应用」中的 VoiceAec 条目。本版在完成页和关于面板里都补了指引。
