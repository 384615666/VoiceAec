## 本版更新

- **缺虚拟声卡时保持暂停**：找不到 CABLE 时不再把处理后的麦克风输出到默认扬声器，避免意外监听和啸叫；面板正常打开并提示安装，装好重启后自动恢复。
- **没有可用麦克风时不再崩溃**：所有采集/播放设备都不可用时，程序以暂停状态启动，面板照常打开（可管理 OBS 插件、查看提示）；接好设备后重新选择并点「恢复处理与输出」即可。
- **临时回退不再变成永久配置**：设备切换时只保存本次真正改动的字段。麦克风拔掉临时回退后，只更换参考设备不会覆盖原麦克风记录，插回重启仍会恢复。
- **安装虚拟声卡不再阻塞面板**：安装改为后台任务，HTTP 立即返回；安装期间状态轮询、电平显示和暂停按钮都正常，按钮显示“正在安装…”。
- **安装器正确判断驱动结果**：修复 cmd 括号块提前展开 `%errorlevel%` 的问题，驱动失败会返回真实退出码；完成页区分“已安装需重启”和“安装失败可重试”，不再误报成功。
