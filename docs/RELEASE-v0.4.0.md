# v0.4.0 · 图标、托盘菜单与 OBS 安装管理

本地实时回声消除桌面工具。本版在 0.3.0 的基础上完成了一轮界面试装与底层修复，并提供安装包。

## 下载

| 文件 | 说明 |
|---|---|
| `VoiceAec-v0.4.0-setup-x64.exe` | **推荐**。安装版，每用户安装、无需管理员权限；创建开始菜单/桌面快捷方式，支持"设置 → 应用"卸载；升级时自动结束正在运行的旧实例。 |
| `VoiceAec-v0.4.0-win-x64.zip` | 便携版，解压即用，配置保存在 exe 旁 `voiceaec.json`。 |

均自包含（免 .NET 运行时），已内置全部模型。

## 本版更新

**界面**

- 全新应用图标（猫咪麦克风）：exe、任务栏、窗口标题栏、托盘统一；16/20/24px 使用放大裁切版本，小尺寸仍可辨认。
- 托盘右键菜单重做为自绘马卡龙风格：圆角与柔和阴影、状态头（运行中/已暂停胶囊）、每项配彩色线性图标、悬停药丸、模式子菜单（彩色圆点 + 当前项对勾）、开机自启开关。
- 托盘菜单与面板文案统一：均衡模式 / 强力模式 / 纯回声消除模式；主菜单显示当前模式。

**命名**

- 产品可见品牌统一为 **VoiceAec**：面板、安装器提示、README、OBS 滤镜显示名。
- 底层引擎文件名保持不变（`liblocalvqe.dll`、`localvqe-*.gguf`、OBS 插件目录 `obs-localvqe`），不影响已有安装与升级。

**功能与修复（0.4.0 主体改动）**

- 新增"暂停并静音"：停止采集、推理与输出，恢复后沿用设备与模式；与 OFF 原声直通不同。
- 高 DPI（PerMonitorV2）；CPU 显示明确为"程序 CPU"；短暂面板请求失败不再误报音频停止。
- 单实例启动：重复运行只激活已有面板，避免两个实例混音。
- OBS 插件一键安装 / 回滚 / 卸载：安装前备份旧版本，卸载恢复备份并保留用户后来新增的文件；OBS 运行时拒绝操作。
- 设备自动适配与热切换：默认通信麦克风 + 默认播放设备 + CABLE Input；主参考与第二参考均支持"播放设备回采或另一只麦克风"。
- **v1.4-AEC 数值修复**：修正自适应滤波器限幅后的协方差舍入残差，数学函数对照最大差从约 0.275 降至 1.26e-5；保留历史基准，未放宽测试容差。
- 面板安全：本地随机令牌 + 仅回环访问，裸 API 请求被拒绝。

## 升级与注意事项

1. 从 0.3.0 升级：运行安装包即可；安装器会强制结束仍在运行/托盘中的 VoiceAec。
2. 之前通过面板安装过 OBS 插件的用户：**在面板点一次"一键安装到 OBS"**（需 UAC），OBS 滤镜名会从 LocalVQE 变为 VoiceAec。已安装目录的旧本地化文件权限为只读，程序无法就地改名。
3. 便携版与安装版不要同时运行（单实例机制会互相激活）。
4. 目标机器仍需自备 VB-CABLE 虚拟声卡；WebView2 运行时 Windows 10/11 一般已自带。
