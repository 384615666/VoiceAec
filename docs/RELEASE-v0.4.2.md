# v0.4.2 · 界面细节修正

## 下载

| 文件 | 说明 |
|---|---|
| `VoiceAec-v0.4.2-setup-x64.exe` | **推荐**。安装版，每用户安装、无需管理员权限。 |
| `VoiceAec-v0.4.2-win-x64.zip` | 便携版，解压即用。 |

均自包含（免 .NET 运行时），已内置全部模型。**本程序不会安装任何虚拟声卡**，需自行安装 VB-CABLE。

## 本版更新

- 窗口标题、页面标题、安装包描述统一为 **VoiceAec**，去掉尚未定名的中文副标题。
- 顶栏左侧品牌区改用软件图标（猫咪麦克风），点击图标或 "VoiceAec" 文字即可打开「关于」；移除了右上角的 ⓘ 按钮，顶栏右端回到「暂停并静音」收尾。
- 底栏使用提示改为小白文案：「打开 QQ 或游戏语音，把『麦克风』选成 CABLE Output；声音继续从『耳机』播放…」，并新增 **打开系统声音设置** 按钮，一键跳到 Windows「设置 → 系统 → 声音」。
- 其余与 v0.4.1 一致（关于面板、新图标、自绘托盘菜单、OBS 插件管理）。

## 升级说明

- 运行安装包即可覆盖升级，安装器会自动结束旧实例。
- 已安装过 OBS 插件的用户：在面板点一次"一键安装到 OBS"后，OBS 滤镜名会显示 VoiceAec。
