# v0.4.3 · 默认安装虚拟声卡

## 下载

| 文件 | 说明 |
|---|---|
| `VoiceAec-v0.4.3-setup-x64.exe` | **推荐**。安装版，每用户安装；默认一并安装 VB-CABLE 虚拟声卡（可取消）。 |
| `VoiceAec-v0.4.3-win-x64.zip` | 便携版，解压即用；首次启动可按面板提示一键安装虚拟声卡。 |

均自包含（免 .NET 运行时），已内置全部模型。

## 本版更新

- **安装包默认安装 VB-CABLE**：向导新增"必需组件"步骤，默认勾选。安装时通过 VB-Audio 官方安装程序静默安装虚拟声卡（需要管理员授权），装完提示重启；不想装可取消勾选。
- **缺少虚拟声卡不再崩溃**：以前找不到 `CABLE Input` 会直接退出且没有任何提示；现在自动回退到默认播放设备，面板顶部出现黄色引导条：一键安装虚拟声卡 / 官网下载 / 重新检测。
- **便携版也能一键装**：程序内置官方驱动包（官方原包，SHA256 校验），也可按需从官网下载并校验后安装；取消管理员授权或失败时会给出明确提示。
- **许可与署名**：VB-CABLE 是 VB-Audio 的捐赠软件（www.vb-cable.com），VoiceAec 只分发未修改的官方包，安装界面与 `THIRD-PARTY-NOTICES.md` 均已标注；卸载 VoiceAec **不会**移除虚拟声卡。
- 其余与 v0.4.2 一致（关于面板、新图标、托盘菜单、OBS 插件管理）。

## 升级说明

- 从旧版升级：运行安装包即可，安装器会自动结束旧实例。已装过 VB-CABLE 的机器会在组件步骤再次运行官方安装程序（幂等），也可取消勾选。
- 装完虚拟声卡**需要重启电脑**设备才会出现；重启前面板会持续显示引导条。
